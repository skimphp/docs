SKIM features an **AI-Native Documentation Pipeline** that keeps humans and AI agents on the same page. Every core file and framework module ends with `#AI*` comments describing the machine-readable contract.

### How It Works

Instead of interrupting developer reading flow with inline comments, all machine-readable metadata sits at the very end of PHP source files as plain comment lines:

```php
// app/Controllers/HomeController.php
final class HomeController {
    public function index(Response $res): Response {
        return $res->view('home');
    }
}

#AI:class
#AI symbol: App\Controllers\HomeController
#AI title: HomeController
#AI description: Renders the landing page.
#AI lifecycle: instantiated per request, invoked by router
```

`#AI:class` marks the class block, `#AI:<method>` blocks describe methods (`#AI signature:`, `#AI contract:`, `#AI param_details:` …). A simple AST-based scanner parses them into accurate, structured documentation.

### The CLI Pipeline

```bash
php skim docs:extract   # scans #AI* blocks across source files → llm.json
php skim docs:llm       # llm.json → llm.md — a single file to paste into any LLM
php skim docs:site      # llm.json → MDX pages for this docs site
php skim docs:validate  # checks annotation coverage against a threshold
```

### Run as a Local MCP Server

Because SKIM parses these annotations into structured JSON, your codebase structure can be served to AI agents:

1.  Add `#AI*` annotations to your own project files and run `php skim docs:extract`.
2.  Start the SKIM MCP (Model Context Protocol) server:
    ```bash
    php skim mcp:serve
    ```
    or install it into your IDE config:
    ```bash
    php skim mcp:install
    ```
3.  Point your IDE agent at the server. Your AI assistant reads real contracts instead of hallucinating your APIs.

<NoteBox>
**Designed for Local Models**

The annotation and generation pipeline is compact enough to run with lightweight local models — no expensive cloud LLM APIs are required to generate or consume these docs.
</NoteBox>
