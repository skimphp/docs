---
title: Config & Env
description: Managing application settings and environment variables in SKIM.
---

Application configuration in SKIM resides inside the `config/` directory as plain PHP files returning arrays — no YAML, no INI. This gives zero parsing overhead, IDE autocompletion, and full opcache compatibility.

### Accessing Config

Read configuration values using dot-notation via the `config()` helper (or `Config::get()`):

```php
// Reads 'default' key from config/db.php
$dbHost = config('db.default.host');

// Class equivalent
$debug = \Skim\Core\Config::get('app.debug', false);
```

Config is **lazy-loaded** on the first read — the framework does not scan `config/` until a value is actually requested, keeping the initial boot footprint minimal.

### Environment Variables

Environment variables are read from your `.env` file at the project root, on demand:

```ini
DB_HOST=127.0.0.1
DB_PORT=3306
```

Inside configuration files, use the `env()` helper:

```php
// config/db.php
return [
    'default' => [
        'host' => env('DB_HOST', '127.0.0.1'),
        'port' => env('DB_PORT', 3306),
    ],
];
```

Env is **lazy-loaded** the same way — `.env` is not parsed until `env()` / `Env::get()` is first called.

### Environment Loading Priority

For seamless containerization and CI/CD:

1.  **OS Environment Variables** (`$_SERVER`, `$_ENV`): pre-existing variables on the system/Docker/Kubernetes level take highest precedence.
2.  **`.env` file values**: act as local development fallbacks, used only when no OS variable is set.

### Compiled Cache (Production)

For production, SKIM pre-compiles config and env into pure PHP arrays served straight from OPcache shared memory:

```bash
php skim cache:build
```

This generates three files in `storage/config_cache/`:
- `env.php` — compiled `.env` values
- `config.php` — compiled `config/*.php` values
- `extensions.php` — extension manifest

In development (`APP_DEBUG=true`), the framework automatically falls back to raw parsing when the source files are newer than the cache.
