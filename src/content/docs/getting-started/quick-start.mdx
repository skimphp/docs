---
title: Quick Start
description: Get up and running with SKIM Framework in less than 5 minutes.
---

Follow this guide to create a new SKIM project and run it locally.

### Prerequisites

*   PHP 8.5 or higher
*   Composer
*   Docker & Docker Compose (recommended — ships with the skeleton)

### 1. Create a New Project

Create a project from the SKIM skeleton:

```bash
composer create-project skim/skeleton my-app
cd my-app
```

### 2. Configure Environment

Copy the example environment file:

```bash
cp .env.example .env
```

Open `.env` to configure database and Redis credentials.

### 3. Start Development Services

Bring up the pre-configured environment:

```bash
docker compose up -d
```

This starts:
*   `app` — PHP 8.5 with the built-in web server (OPcache + JIT), port **8080**
*   `mysql` and `pgsql` — database containers
*   `redis` — cache, session & queue backend

### 4. Run Migrations

```bash
docker compose exec app php skim migrate:up
```

### 5. Open in Browser

```
http://localhost:8080
```

You should see the SKIM welcome screen.
