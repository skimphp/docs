`Skim\Core\Request` wraps PHP superglobals into a typed, testable object. It is injected by the container into controllers and middleware — never instantiated manually in application code. The same instance is shared across the entire request lifecycle.

```txt
Symbol: Skim\Core\Request
Source: src/Core/Request.php
Lifecycle: created once by App::run() via fromGlobals(), shared across middleware and controller
Test seam: Request::make() fabricates requests from explicit arrays without superglobals
```

<CodeExample label="Basic usage" source="llm-generated">
```php
public function store(Request $req, Response $res): mixed {
    $email = $req->post('email');
    $data  = $req->json();
    return $res->json(['ip' => $req->ip()]);
}
```
</CodeExample>

<WarningBox>

X-Forwarded-For is trusted without proxy validation — do not use ip() as a security boundary

</WarningBox>

<WarningBox>

Mutations to $_GET after fromGlobals() are not reflected

</WarningBox>

## Architecture

The request is a value object created once per HTTP cycle. Route params are injected after dispatch by the framework. The make() factory delegates to request_factory for test fabrication.

<NoteBox>

Wraps $_GET, $_POST, $_SERVER, $_FILES, $_COOKIE, and php://input. Never access superglobals directly in app code.

</NoteBox>

## Construction

<ApiMethod name="fromGlobals">

<ApiSignature>

```php
public static function fromGlobals(): static
```

</ApiSignature>

Creates a request from PHP superglobals. Called once by App::run(). Reads superglobals at call time.

<CodeExample label="Basic usage" source="llm-generated">
```php
// Called internally by App::run()
$req = Request::fromGlobals();
```
</CodeExample>

</ApiMethod>

<ApiMethod name="make">

<ApiSignature>

```php
public static function make(mixed ...$args): static
```

</ApiSignature>

Fabricates a request from explicit arrays for testing. Delegates to RequestFactory::make().

<ApiParam name="$args" type="mixed">

Arguments forwarded to RequestFactory::make().

</ApiParam>

<CodeExample label="Basic usage" source="llm-generated">
```php
$req = Request::make('POST', '/users', headers: ['Content-Type' => 'application/json'], rawBody: '{"name":"John"}');
```
</CodeExample>

<NoteBox>

For test use only — not for production request creation.

</NoteBox>

</ApiMethod>

<ApiParam name="$key" type="string" required>

POST field name.

</ApiParam>

<ApiParam name="$default" type="mixed">

Returned when the key is absent.

</ApiParam>

</ApiMethod>

<ApiMethod name="input">

<ApiSignature>

```php
public function input(string $key, mixed $default = null): mixed
```

</ApiSignature>

Searches GET first, then POST. Returns the first match.

<ApiParam name="$key" type="string" required>

Field name to search.

</ApiParam>

<ApiParam name="$default" type="mixed">

Returned when absent from both sources.

</ApiParam>

</ApiMethod>

<ApiMethod name="json">

<ApiSignature>

```php
public function json(): array
```

</ApiSignature>

Parses the JSON body on first call and caches the result. Returns empty array when Content-Type is not application/json or body is invalid JSON.

<CodeExample label="Basic usage" source="llm-generated">
```php
$data = $req->json(); // ['name' => 'John', 'age' => 30]
```
</CodeExample>

<NoteBox>

Never throws on malformed JSON. Safe to call multiple times per request.

</NoteBox>

</ApiMethod>

<ApiMethod name="file">

<ApiSignature>

```php
public function file(string $key): ?array
```

</ApiSignature>

Returns the uploaded file array from $_FILES, or null if absent or no file uploaded.

<ApiParam name="$key" type="string" required>

File input field name.

</ApiParam>

</ApiMethod>

## Headers & IP

<ApiMethod name="header">

<ApiSignature>

```php
public function header(string $name): ?string
```

</ApiSignature>

Returns a request header value. Name is case-insensitive. Normalizes to $_SERVER HTTP_ format.

<ApiParam name="$name" type="string" required>

Header name (case-insensitive).

</ApiParam>

</ApiMethod>

<ApiMethod name="ip">

<ApiSignature>

```php
public function ip(): string
```

</ApiSignature>

Returns the client IP. Reads X-Forwarded-For first, falls back to REMOTE_ADDR.

<WarningBox>

Does not validate X-Forwarded-For against trusted proxies — not a security boundary

</WarningBox>

</ApiMethod>
