`Skim\Core\Response` builds the HTTP response through fluent method chaining. Controllers return the response object

```txt
Symbol: Skim\Core\Response
Source: src/Core/Response.php
Lifecycle: created fresh per request by App::run(), populated by controller, sent after middleware
Test seam: inspect via getStatus(), getBody(), getHeaders(), getJson() without calling send()
```

<CodeExample label="Basic usage" source="llm-generated">
```php
return $res->status(201)->json(['id' => $user->id]);
return $res->view('users/show', ['user' => $user]);
return $res->redirect('/login');
```
</CodeExample>

<WarningBox>

stream() sends headers inline — middleware response modifications after stream() have no effect

</WarningBox>

<WarningBox>

Never echo or die in controllers — always return $res-&gt;...

</WarningBox>

## Architecture

The response is a mutable builder object. send() handles three body types: normal string, stream sentinel (\x00stream), and file sentinel (\x00file:path). This avoids buffering large files in memory.

<NoteBox>

Most methods return $this for fluent chaining. The #[\NoDiscard] attribute on status() prevents silently losing the status code.

</NoteBox>

## Streaming & Downloads

<ApiMethod name="stream">

<ApiSignature>

```php
public function stream(callable $callback, ?string $driver = null): static
```

</ApiSignature>

Sends SSE headers immediately, disables output buffering, and passes an Sse or resolved driver instance to the callback. Driver is resolved from the container so apps/extensions can override with one bind().

<ApiParam name="$callback" type="callable" required>

Receives an Sse or driver instance to emit events.

</ApiParam>

<ApiParam name="$driver" type="?string">

Optional driver class to resolve from the container. Falls back to config('realtime.driver'). Defaults to plain Sse.

</ApiParam>

<CodeExample label="Basic usage" source="llm-generated">
```php
return $res->stream(function(Sse $sse) {
    $sse->send('message', 'Hello');
});

return $res->stream(function(ElementPatcher $ds) {
    $ds->patch('<div id="status">Active</div>', '#status');
}, driver: Datastar::class);
```
</CodeExample>

<WarningBox>

Headers are sent inline — middleware response modifications after this call have no effect

</WarningBox>

</ApiMethod>
