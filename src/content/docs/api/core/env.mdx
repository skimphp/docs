`Skim\Core\Env` lazy-loads a `.env` file on first `get()` call and provides typed access to environment variables. OS environment variables (`$_SERVER`, `$_ENV`) always take priority over `.env` values, ensuring deployment-injected values are never silently overwritten. No `putenv()` or `$_ENV` mutations — internal cache only.

```txt
Symbol: Skim\Core\Env
Source: src/Core/Env.php
Lifecycle: static facade, .env lazy-loaded on first get() call
Test seam: set(), reset()
```

<CodeExample label="Basic usage" source="llm-generated">
```php
$debug = Env::get('APP_DEBUG', false);   // auto-loads .env on first call
```
</CodeExample>

<WarningBox>

OS environment variables in $_SERVER or $_ENV always override .env file values — this is intentional

</WarningBox>

## Architecture

<LifecycleFlow>

```txt
Env::get(key)
-> !$loaded check
-> auto-load basePath('.env')
-> idempotent check
-> is_file check
-> parse lines into cache
-> $_SERVER[$key] ?? $_ENV[$key] ?? Cache[$key] ?? default -> type cast
```

</LifecycleFlow>

Own implementation avoids the vlucas/phpdotenv dependency. putenv() removed to avoid process-global mutations — internal cache only.

<NoteBox>

Own implementation avoiding vlucas/phpdotenv dependency. The parsing logic is approximately 30 lines.

</NoteBox>

## Read API

<ApiMethod name="get">

<ApiSignature>

```php
public static function get(string $key, mixed $default = null): mixed
```

</ApiSignature>

Returns the environment variable value for the given key. Auto-loads .env on first call when not yet loaded. Read priority: $_SERVER → $_ENV → internal cache → $default. Casts string values 'true', 'false', and 'null' (case-insensitive) to native PHP types.

<ApiParam name="$key" type="string" required>

Environment variable name.

</ApiParam>

<ApiParam name="$default" type="mixed">

Fallback value returned as-is when the key is not found in any source.

</ApiParam>

<NoteBox>

Lookup order is $_SERVER, then $_ENV, then internal cache. Numeric strings are NOT cast to int or float.

</NoteBox>

</ApiMethod>

<ApiMethod name="all">

<ApiSignature>

```php
public static function all(): array
```

</ApiSignature>

Returns all cached environment variables as a flat array. Auto-loads on first call. Includes values from .env and set() overrides. Does not include $_SERVER or $_ENV values.

</ApiMethod>

<ApiMethod name="loadCompiledCache">

<ApiSignature>

```php
private static function loadCompiledCache(): bool
```

</ApiSignature>

Attempts to load env values from a pre-compiled PHP array cache at storage/config_cache/env.php. Returns false when the cache file is missing or stale (APP_DEBUG=true and .env newer than cache). Sets loaded flag on success.

</ApiMethod>

## Write API

<ApiMethod name="load">

<ApiSignature>

```php
public static function load(string $path): void
```

</ApiSignature>

Parses the .env file at the given path into the internal cache only. Idempotent — only the first call has effect. Silently skips missing files. OS variable priority is enforced at read time in get(), not at load time.

<ApiParam name="$path" type="string" required>

Absolute path to the .env file. Typically basePath('.env').

</ApiParam>

<CodeExample label="Basic usage" source="llm-generated">
```php
Env::load(basePath('.env'));
```
</CodeExample>

<WarningBox>

Idempotent — calling load() a second time with a different path has no effect

</WarningBox>

<NoteBox>

Lines starting with # are treated as comments. Surrounding single or double quotes are stripped from values.

</NoteBox>

</ApiMethod>

## Testing Hooks

<ApiMethod name="set">

<ApiSignature>

```php
public static function set(string $key, mixed $value): void
```

</ApiSignature>

Overrides a single environment variable in the internal cache only. Sets the loaded flag to prevent auto-load from overwriting test values. Does not touch $_ENV or putenv(). Intended for test isolation.

<ApiParam name="$key" type="string" required>

Environment variable name to override.

</ApiParam>

<ApiParam name="$value" type="mixed" required>

Value to store. Persists for the process lifetime until reset().

</ApiParam>

<NoteBox>

Override is visible to Env::get() but not to getenv() or $_ENV readers.

</NoteBox>

</ApiMethod>

<ApiMethod name="reset">

<ApiSignature>

```php
public static function reset(): void
```

</ApiSignature>

Clears the internal cache and resets the loaded flag, allowing a subsequent load() call to re-parse the .env file. Use in test tearDown().

</ApiMethod>
