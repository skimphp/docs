`HttpResponse` wraps a `Skim\Core\Response` and provides fluent assertion methods powered by Pest's `expect()`. All `assert_*` methods return `$this` for chaining.

```txt
Symbol: Skim\Testing\HttpResponse
Source: src/Testing/HttpResponse.php
Lifecycle: returned by PendingRequest/HttpClient HTTP methods, used inline in test cases
Fallback: n/a — test-only class
Test seam: instantiate directly or receive from HttpClient methods
```

<CodeExample label="Basic usage" source="llm-generated">
```php
$client->post('/api/users', json: ['name' => 'John'])
    ->assertCreated()
    ->assertJson(['name' => 'John']);
```
</CodeExample>

## Architecture

<LifecycleFlow>

```txt
PendingRequest::send() -> new HttpResponse($res)
-> test calls assertOk()->assertJson([...])
```

</LifecycleFlow>

Thin wrapper over core response — adds test assertion ergonomics without modifying response behavior.

<NoteBox>

assertJson() uses subset matching (toMatchArray), not exact equality.

</NoteBox>
