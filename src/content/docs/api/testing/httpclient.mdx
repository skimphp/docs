`HttpClient` provides a fluent API for testing HTTP endpoints in-process. Each method creates a fresh `PendingRequest`, so configuration does not leak between calls.

```txt
Symbol: Skim\Testing\HttpClient
Source: src/Testing/HttpClient.php
Lifecycle: instantiated per-test, wraps an app instance
Fallback: n/a — test-only class
Test seam: instantiate directly in test cases with the app under test
```

<CodeExample label="Basic usage" source="llm-generated">
```php
$client = new HttpClient($app);
$client->actingAs($user)->post('/api/posts', json: ['title' => 'Hello']);
$client->get('/api/posts')->assertOk()->assertJson([...]);
```
</CodeExample>

## Architecture

<LifecycleFlow>

```txt
new HttpClient($app)
-> HttpClient::get/post/etc()
-> new PendingRequest($app)
-> PendingRequest::send()
-> App::dispatch()
-> HttpResponse
```

</LifecycleFlow>

Thin convenience layer over PendingRequest — each call creates a fresh instance to prevent state leakage.

<NoteBox>

Use actingAs() for authenticated routes, withSession() for session-dependent routes, withoutMiddleware() to isolate controller logic.

</NoteBox>
