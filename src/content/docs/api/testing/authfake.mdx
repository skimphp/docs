`AuthFake` is a minimal test double for the auth service. It always reports the user as authenticated and returns the injected user object directly.

```txt
Symbol: Skim\Testing\AuthFake
Source: src/Testing/AuthFake.php
Lifecycle: instantiated per-test, bound into the container via App::bind()
Fallback: n/a — test-only class
Test seam: bind into container via $app->bind('auth', fn() => new AuthFake($user))
```

<CodeExample label="Basic usage" source="llm-generated">
```php
$fake = new AuthFake(User::find(1));
$app->bind('auth', fn() => $fake);
```
</CodeExample>

## Architecture

<LifecycleFlow>

```txt
new AuthFake($user)
-> bind to container
-> controller calls Auth::check() -> true
```

</LifecycleFlow>

Intentionally minimal — only the methods the auth middleware and controllers call.

<NoteBox>

The user object must have an `id` property for id() to return non-null.

</NoteBox>
