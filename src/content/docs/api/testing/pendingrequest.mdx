`PendingRequest` is an immutable builder that configures and dispatches in-process HTTP requests. Each configuration method returns a clone, preventing state leakage between test assertions.

```txt
Symbol: Skim\Testing\PendingRequest
Source: src/Testing/PendingRequest.php
Lifecycle: created per-request by HttpClient, cloned on each configuration call, consumed on HTTP method call
Fallback: n/a — test-only class
Test seam: use via HttpClient or instantiate directly with an app instance
```

<CodeExample label="Basic usage" source="llm-generated">
```php
$req = new PendingRequest($app);
$req->actingAs($user)
    ->withHeaders(['Accept' => 'application/json'])
    ->post('/api/posts', json: ['title' => 'Test'])
    ->assertCreated();
```
</CodeExample>

## Architecture

<LifecycleFlow>

```txt
HttpClient::method() -> new PendingRequest($app)
-> actingAs/withHeaders/etc() -> clone
-> get/post/etc() -> send()
-> RequestFactory::make()
-> clone app
-> bind fakes
-> App::dispatch()
-> HttpResponse
```

</LifecycleFlow>

Immutable builder pattern — each configuration call returns a clone, making it safe to reuse a base PendingRequest across multiple assertions.

<NoteBox>

When $json is non-empty on post(), Content-Type is automatically set to application/json.

</NoteBox>
