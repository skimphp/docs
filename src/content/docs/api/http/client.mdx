`client` wraps PHP's native `file_get_contents` + `stream_context_create` for outbound HTTP. It returns immutable `HttpResponse` objects and never throws on non-2xx status codes.

```txt
Symbol: Skim\Http\Client
Source: src/Http/Client.php
Lifecycle: instantiated per-service or per-request
Test seam: Client::fake() returns a FakeClient that records requests and returns stubs
```

<CodeExample label="Basic usage" source="llm-generated">
```php
$http = new Client(['base_url' => 'https://api.example.com', 'timeout' => 5]);
$resp = $http->get('/users', ['page' => 1]);
if ($resp->ok()) { $users = $resp->json(); }
```
</CodeExample>

<ApiMethod name="fake">

</ApiSignature>

Returns a FakeClient that intercepts all HTTP requests, records them, and returns stub responses.

<ApiParam name="$stubs" type="array">

Map of 'METHOD URL' =&gt; response stub arrays or HttpResponse objects.

</ApiParam>

<CodeExample label="Basic usage" source="llm-generated">
```php
$http = Client::fake(['GET https://api.example.com/users' => ['status' => 200, 'body' => []]]);
$resp = $http->get('https://api.example.com/users');
$http->assertSent('GET', 'users');
```
