`FakeClient` extends `client` to intercept all HTTP requests in tests. It records every request for later assertion and returns configurable stub responses without making real network calls.

```txt
Symbol: Skim\Http\FakeClient
Source: src/Http/FakeClient.php
Lifecycle: created via Client::fake()
Test seam: Client::fake($stubs) factory
```

<CodeExample label="Basic usage" source="llm-generated">
```php
$http = Client::fake([
    'GET https://api.example.com/users' => ['status' => 200, 'body' => [['id' => 1]]],
]);
$resp = $http->get('https://api.example.com/users');
$http->assertSent('GET', 'users');
```
</CodeExample>

<ApiSignature>


</ApiSignature>

Throws RuntimeException when no recorded request matches the given method and URL substring.

<ApiParam name="$method" type="string" required>

</ApiParam>

<ApiParam name="$url" type="string" required>
