`HttpResponse` is an immutable value object returned by all `client` HTTP methods. It wraps status code, body, and headers without throwing on non-2xx responses.

```txt
Symbol: Skim\Http\HttpResponse
Source: src/Http/HttpResponse.php
Lifecycle: created by Client::send() or fromStream()
Test seam: construct directly with known values
```

<CodeExample label="Basic usage" source="llm-generated">

    $users = $resp->json();
}
