## Slugs & Truncation

<ApiMethod name="slug">

<ApiSignature>

```php
public static function slug(string $text): string
```

</ApiSignature>

Converts text to a URL-safe slug by lowercasing, stripping non-alphanumeric characters (Unicode-aware), and collapsing whitespace/dashes into single dashes.

<ApiParam name="$text" type="string" required>

Input text to slugify.

</ApiParam>

</ApiMethod>

<ApiMethod name="excerpt">

<ApiSignature>

```php
public static function excerpt(string $text, int $length = 100, string $suffix = '...', bool $wordBoundary = true): string
```

</ApiSignature>

Truncates text to $length characters. When $wordBoundary is true, backs up to the last space to avoid mid-word cuts. Appends $suffix only when truncation occurs.

<ApiParam name="$text" type="string" required>

Input text to truncate.

</ApiParam>

<ApiParam name="$length" type="int">

Maximum character count before truncation. Default 100.

</ApiParam>

<ApiParam name="$suffix" type="string">

Appended when text is truncated. Default '...'.

</ApiParam>

<ApiParam name="$wordBoundary" type="bool">

When true, avoids cutting mid-word. Default true.

</ApiParam>

</ApiMethod>

## Case Conversion

<ApiMethod name="toSnake">

<ApiSignature>

```php
public static function toSnake(string $str): string
```

</ApiSignature>

Converts CamelCase or PascalCase to snake_case. Handles consecutive capitals correctly (e.g. 'HTMLParser' → 'html_parser').

<ApiParam name="$str" type="string" required>

CamelCase input.

</ApiParam>

</ApiMethod>

<ApiMethod name="toCamel">

<ApiSignature>

```php
public static function toCamel(string $str): string
```

</ApiSignature>

Converts snake_case to camelCase (first letter lowercase).

<ApiParam name="$str" type="string" required>

snake_case input.

</ApiParam>

</ApiMethod>
