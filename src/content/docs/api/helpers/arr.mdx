`arr` provides common array transformations used across controllers, models, and services. It wraps PHP 8.4+ `array_find()` with key=&gt;value shorthand and provides multi-key indexing methods essential for eager-loading relation maps.

```txt
Symbol: Skim\Helpers\Arr
Source: src/Helpers/Arr.php
Lifecycle: stateless — all methods are pure functions
Fallback: none
Test seam: test directly — no mocking needed
```

<CodeExample label="Basic usage" source="llm-generated">
```php
Arr::find(['id' => 5], $users);           // first user with id=5
Arr::mapBy('id', $users);                // [5 => user, 6 => user, ...]
Arr::pluck('name', $users);               // ['John', 'Jane', ...]
```
</CodeExample>

## Architecture

<LifecycleFlow>

```txt
caller invokes static method

-> return value
```

## Indexing

<ApiMethod name="mapBy">

<ApiSignature>

```php
public static function mapBy(string $key, array $items): array
```

</ApiSignature>

Re-indexes an array by a column value. Last-write-wins on key collision.

<ApiParam name="$key" type="string" required>

Column to use as the new key.

</ApiParam>

<ApiParam name="$items" type="array" required>

Array of arrays or objects.

</ApiParam>

<CodeExample label="Basic usage" source="llm-generated">
```php
Arr::mapBy('id', [['id'=>5,'name'=>'J']]); // [5 => ['id'=>5,'name'=>'J']]
```
</CodeExample>

</ApiMethod>

<ApiMethod name="mapCol">

<ApiSignature>

```php
public static function mapCol(string $key, string $val, array $items): array
```

</ApiSignature>

Maps two columns into key→value pairs.

<ApiParam name="$key" type="string" required>

Column for resulting key.

</ApiParam>

<ApiParam name="$val" type="string" required>

Column for resulting value.

</ApiParam>

<ApiParam name="$items" type="array" required>

Array of arrays or objects.

</ApiParam>

<CodeExample label="Basic usage" source="llm-generated">
```php
Arr::mapCol('id', 'name', $rows); // [5 => 'John', 6 => 'Jane']
```
</CodeExample>

</ApiMethod>

<ApiMethod name="mapNested">

</ApiParam>

<ApiParam name="$key2" type="string" required>

Second-level key column.

</ApiParam>

<ApiParam name="$items" type="array" required>

Array of arrays or objects.

</ApiParam>

</ApiMethod>
