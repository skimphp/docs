`log` is the static entry point for all application logging. It resolves the configured handler on first write and records every entry in the profiler for the debug toolbar.

```txt
Symbol: Skim\Log\Log
Source: src/Log/Log.php
Lifecycle: static facade, handler resolved on first log call
Fallback: NullHandler when channel is unrecognized
Test seam: setHandler(), reset()
```

<CodeExample label="Basic usage" source="llm-generated">
```php
Log::error('Payment failed', ['order_id' => $id, 'reason' => $e->getMessage()]);
Log::info('User logged in', ['user_id' => $user->id]);
```
</CodeExample>

## Architecture

<LifecycleFlow>

```txt
Log::error() / info() / etc.
-> write()
-> debug_backtrace for caller
-> Profiler::log()
-> handler()
-> resolveHandler() if null
-> handler->write()
```

</LifecycleFlow>

## Testing Hooks

<ApiMethod name="setHandler">

<ApiSignature>

```php
public static function setHandler(LogHandler $handler): void
```

</ApiSignature>

Replaces the active handler. Use in tests or to swap in Monolog for production channels.

<ApiParam name="$handler" type="LogHandler" required>

Custom handler implementation.

</ApiParam>

<CodeExample label="Basic usage" source="llm-generated">
```php
Log::setHandler(new NullHandler());
```
</CodeExample>

</ApiMethod>

<ApiMethod name="reset">

<ApiSignature>

```php
public static function reset(): void
```

</ApiSignature>

Clears the cached handler. The next log call resolves the handler again from config.

</ApiMethod>

```txt
symbol: Skim\Log\Log
role: static log facade
layer: log
lifecycle: static facade, handler resolved on first log call
owns: handler instance cache
flow: Log::level() -> write() -> Profiler::log() -> handler()->write()
entry_points:
  - debug
  - info
  - notice
  - warning
  - error
  - critical
  - alert
  - emergency
config_reads:
  - app.log.channel
  - app.log.path
  - app.log.level
  - app.log.days
invariants:
  - handler is resolved once and reused until reset() or setHandler()
  - every write records in Profiler::log
  - unknown channels fall back to NullHandler
side_effects:
  - Profiler::log records every entry
  - setHandler() replaces active handler
  - reset() forces re-resolution
non_goals:
  - Does not support channels or named loggers
  - Does not format messages beyond sprintf
  - Does not send to external services directly
```
