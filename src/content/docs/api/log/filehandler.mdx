`FileHandler` writes log entries to date-suffixed files and automatically prunes files older than the configured retention period. It is the default log backend when no external service is configured.

```txt
Symbol: Skim\Log\FileHandler
Source: src/Log/FileHandler.php
Lifecycle: created by Log::resolveHandler()
Test seam: inject NullHandler via Log::setHandler() to skip file I/O
```

// Produces: storage/logs/app-2024-01-15.log
