`datastar` is the official Datastar v1 driver for SKIM. It emits `datastar-patch-elements` and `datastar-patch-signals` events over an injected SSE transport, enabling server-driven UI updates without hand-written JavaScript state.

```txt
Symbol: Skim\Realtime\Datastar
Source: src/Realtime/Datastar.php
Lifecycle: created per-stream by Response::stream() or container resolution
Test seam: capture output with ob_start()/ob_get_clean() in tests
```

<CodeExample label="Basic usage" source="llm-generated">
```php
return $res->stream(function(ElementPatcher $ds) {
    $ds->patch('<div id="status">Active</div>', '#status', 'inner');
    $ds->signals(['loading' => false]);
});
```
</CodeExample>

<WarningBox>

run() executes arbitrary JavaScript in the browser — use sparingly and never with user-supplied input

</WarningBox>

<ApiMethod name="run">

<ApiSignature>

```php

```

</ApiSignature>

Appends a &lt;script&gt; element to the body via datastar-patch-elements. The browser evaluates it and Datastar removes it.
