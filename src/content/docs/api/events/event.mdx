`event` is the static event bus for decoupling side effects. Listeners run synchronously in priority order during emit(). Async dispatch via emitAsync() delegates to the queue worker.

```txt
Symbol: Skim\Events\Event
Source: src/Events/Event.php
Lifecycle: static, listeners registered during boot phase
Test seam: off() to clear listeners
```

<CodeExample label="Basic usage" source="llm-generated">
```php
Event::on(UserCreatedEvent::class, fn($e) => Log::info("User {$e->user->id} created"));
Event::emit(new UserCreatedEvent($user));
```
</CodeExample>

## Dispatch

<ApiMethod name="emit">

<ApiSignature>

```php
public static function emit(object|string $payload, mixed $data = null): void
```

</ApiSignature>

Dispatches the event to all registered listeners in priority order. For typed events, the object is passed directly. For string events, $data is the payload. All listeners run synchronously.

<ApiParam name="$payload" type="object" required>

Event object (typed) or event name (string).

</ApiParam>

<ApiParam name="$data" type="mixed">

Payload for string events. Ignored for typed events.

</ApiParam>

<CodeExample label="Basic usage" source="llm-generated">
```php
Event::emit(new UserCreatedEvent($user));
Event::emit('user.created', ['id' => $user->id]);
```
</CodeExample>

</ApiMethod>

<ApiMethod name="emitAsync">

<ApiSignature>

```php
public static function emitAsync(object|string $payload, mixed $data = null): void
```

</ApiSignature>

Pushes the event to the queue for async processing in a worker process. Requires skim/queue to be installed.

<ApiParam name="$payload" type="object" required>

Event object or event name.

</ApiParam>

<ApiParam name="$data" type="mixed">

Payload for string events.

</ApiParam>

<CodeExample label="Basic usage" source="llm-generated">
```php
Event::emitAsync(new ReportGeneratedEvent($report));
```
</CodeExample>

<ApiThrows type="\RuntimeException">

When skim/queue is not installed.

</ApiThrows>

</ApiMethod>

Captures the current listener registry as the boot-time snapshot. #AI:capture_boot_snapshot

Call once after boot/extensions are registered in worker mode. The snapshot
is restored by resetRequest() on every subsequent request so boot-time
listeners survive while request-time listeners are dropped.
