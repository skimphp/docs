`FileSessionDriver` wraps PHP's native `session_*` functions with a configured save path and secure cookie parameters. It is the default session driver for single-server setups.

```txt
Symbol: Skim\Session\FileSessionDriver
Source: src/Session/FileSessionDriver.php
Lifecycle: instantiated by session facade, start() called once per request
Fallback: none — this is itself the fallback driver
Test seam: use SessionFake in tests instead
```

<CodeExample label="Basic usage" source="llm-generated">
```php
$driver = new FileSessionDriver(storagePath('sessions'), 7200);
$driver->start();
```
</CodeExample>

<WarningBox>

flush() destroys all session data irreversibly

</WarningBox>

<WarningBox>

Direct $_SESSION access bypasses driver abstraction

</WarningBox>

## Architecture

<LifecycleFlow>

```txt
Session::start()
-> FileSessionDriver::start()
-> mkdir if needed
-> session_set_cookie_params()
-> session_start()
-> $_SESSION available
```

</LifecycleFlow>

Wraps PHP native sessions to enable test injection via the SessionDriver interface.

<NoteBox>

Not suitable for multi-server deployments — session files are local to one server. Use RedisSessionDriver for load-balanced setups.

</NoteBox>

## Lifecycle

<ApiMethod name="start">

<ApiSignature>

```php
public function start(): void
```

</ApiSignature>

Starts or resumes a file-backed session. No-ops when a session is already active. Creates the save_path directory if missing and configures secure cookie params.

</ApiMethod>

<ApiMethod name="regenerate">

<ApiSignature>

```php
public function regenerate(): void
```

</ApiSignature>

Regenerates the session ID and deletes the old session file. Call after login/logout to prevent session fixation.

</ApiMethod>

<ApiMethod name="flush">

<ApiSignature>

```php
public function flush(): void
```

</ApiSignature>

Destroys session data and invalidates the session.

<WarningBox>

Irreversible — all session data for this ID is lost immediately

</WarningBox>

</ApiMethod>
