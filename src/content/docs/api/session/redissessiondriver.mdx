`RedisSessionDriver` stores each session as a single serialized JSON blob in Redis, keyed by a configurable prefix plus the session ID. It is required for load-balanced deployments where file-based sessions would not be shared across workers.

```txt
Symbol: Skim\Session\RedisSessionDriver
Source: src/Session/RedisSessionDriver.php
Lifecycle: instantiated by session facade, start() called once per request, Redis connection opened lazily
Fallback: none — use FileSessionDriver when Redis is unavailable
Test seam: use SessionFake in tests instead
```

<CodeExample label="Basic usage" source="llm-generated">
```php
$driver = new RedisSessionDriver('redis', 6379, null, 'sess_', 7200);
$driver->start();
```
</CodeExample>

<WarningBox>

flush() deletes session data from Redis irreversibly

</WarningBox>

<WarningBox>

Each write re-serializes the full session — avoid storing large payloads

</WarningBox>

## Architecture

<LifecycleFlow>

```txt
Session::start()
-> RedisSessionDriver::start()
-> read PHPSESSID cookie or generateId()
-> Redis GET
-> json_decode
-> Redis EXPIRE
-> setcookie if new
```

</LifecycleFlow>

Stores session as a single JSON blob rather than individual keys — simpler but means every write is O(session_size).

<NoteBox>

Each set()/delete() triggers a full JSON re-serialization and Redis write. For typical session sizes (&lt;4KB) this is acceptable.

</NoteBox>

## Lifecycle

<ApiMethod name="start">

<ApiSignature>

```php
public function start(): void
```

</ApiSignature>

Starts or resumes a Redis-backed session. Reads session ID from cookie or generates new one. Loads data from Redis and renews TTL. Sends cookie only for new sessions.

</ApiMethod>

<ApiMethod name="regenerate">

<ApiSignature>

```php
public function regenerate(): void
```

</ApiSignature>

Deletes the old Redis session key, generates a new Session ID, sends a fresh cookie, and persists existing data under the new key.

</ApiMethod>

<ApiMethod name="flush">

<ApiSignature>

```php
public function flush(): void
```

</ApiSignature>

Deletes session data from Redis and expires the session cookie.

<WarningBox>

Irreversible — all session data for this ID is deleted from Redis

</WarningBox>

</ApiMethod>
