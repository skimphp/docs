`ViewException` is thrown by the view system when a template file cannot be resolved or a requested fragment name does not exist in the rendered output.

```txt
Symbol: Skim\View\Exceptions\ViewException
Source: src/View/Exceptions/ViewException.php
Lifecycle: thrown during View::render() or Template::renderFile()
Fallback: n/a — exception type
Test seam: expect this exception in Pest tests for missing templates
```

<CodeExample label="Basic usage" source="llm-generated">
```php
try {
    View::render('nonexistent');
} catch (ViewException $e) {
    Log::error($e->getMessage());
}
```
</CodeExample>
