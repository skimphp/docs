`FragmentExtractor` tokenizes HTML comment markers, validates structural constraints (flat only, balanced pairs), and extracts named fragment content. More robust than the previous regex approach.

Test seam: pass raw HTML strings directly, no file system needed

## Architecture

<LifecycleFlow>

```txt
extract($html, $name)
-> tokenize($html)
-> validateNoNesting($tokens)
-> extractByName($html, $tokens, $name)
-> return trim(substr(...))
```

</LifecycleFlow>

Replaced the regex-based extractor to avoid backtracking issues and to provide meaningful error messages for malformed fragment markup.

<NoteBox>

The parser intentionally limits fragments to one level. This prevents complex nesting bugs and keeps the mental model simple.

</NoteBox>
