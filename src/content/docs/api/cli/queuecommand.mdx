`QueueCommand` implements the `php skim queue:*` family of CLI commands. It dispatches to work (start worker), status (show pending counts), flush (remove pending jobs), and restart (signal workers to stop) sub-commands.

```txt
Symbol: Skim\Cli\Commands\QueueCommand
Source: src/Cli/Commands/QueueCommand.php
Lifecycle: instantiated by kernel, handle() called once per invocation
Fallback: unknown sub-commands print an error and return exit code 1
Test seam: instantiate directly, call setInput() with test args, then handle()
```

<CodeExample label="Basic usage" source="llm-generated">
```php
php skim queue:work [queue] [--sleep=3] [--max-jobs=0]
php skim queue:status
php skim queue:flush [queue]
php skim queue:restart
```
</CodeExample>

<WarningBox>

flush destroys all pending jobs in the specified queue

</WarningBox>

<WarningBox>

work blocks the terminal until stopped

</WarningBox>

## Architecture

<LifecycleFlow>

```txt
handle()
-> arg(0) sub-command
-> match: work -> new Worker() -> worker->work()
status -> Queue::size()
flush -> Queue::flush()
restart -> Queue::redis()->set(restart key)
```

</LifecycleFlow>

Thin CLI wrapper over queue and worker classes. The work sub-command is the only blocking operation — all others return immediately.

## Sub-commands

<ApiMethod name="work">

<ApiSignature>

```php
private function work(): int
```

</ApiSignature>

Starts a long-lived queue worker that blocks on Redis BRPOP. Processes jobs until stopped by signal, max-jobs, or restart signal.

</ApiMethod>

<ApiMethod name="status">

<ApiSignature>

```php
private function status(): int
```

</ApiSignature>

Displays pending job count per queue in an ASCII table.

</ApiMethod>

<ApiMethod name="flush">

<ApiSignature>

```php
private function flush(): int
```

</ApiSignature>

Removes all pending jobs from the specified queue.

<WarningBox>

Destroys all pending jobs in the queue — already-processing jobs are not affected

</WarningBox>

</ApiMethod>

<ApiMethod name="restart">

<ApiSignature>

```php
private function restart(): int
```

</ApiSignature>

Sends a restart signal to all running workers via a Redis timestamp key. Workers stop after completing their current job.

</ApiMethod>
