`CacheBuildCommand` provides the `php skim cache:build` CLI entry point. It generates compiled PHP array files in `storage/config_cache/` for env, config, and extensions, enabling OPcache shared-memory hits with zero parse overhead on subsequent requests.

```txt
Symbol: Skim\Cli\Commands\CacheBuildCommand
Source: src/Cli/Commands/CacheBuildCommand.php
Lifecycle: instantiated by CLI kernel, handle() called once per invocation
Fallback: creates storage/config_cache/ directory if missing
Test seam: run against temp directory, verify generated files are valid PHP arrays
```

<CodeExample label="Basic usage" source="llm-generated">
```php
php skim cache:build
```
</CodeExample>

<WarningBox>

Calls App::instance() which triggers full boot — ensure .env and config/ are present

</WarningBox>

## Architecture

<LifecycleFlow>

```txt
kernel dispatches CacheBuildCommand
-> handle()
-> mkdir storage/config_cache
-> Env::reset()
-> Env::load(.env)
-> write env.php
-> Config::reset()
-> Config::load(config/)
-> write config.php
-> App::instance()
-> write extensions.php
-> success
```

</LifecycleFlow>

Thin CLI wrapper that delegates to env, config, and app facades. The generated files are consumed by Env::loadCompiledCache() and Config::loadCompiledCache().

## Command Execution

<ApiMethod name="handle">

<ApiSignature>

```php
public function handle(): int
```

</ApiSignature>

Builds compiled cache files for env, config, and extensions in storage/config_cache/. Resets env and config before loading to ensure fresh state. Creates the cache directory if missing.

</ApiMethod>
