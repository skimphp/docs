`ExtInstallCommand` implements the `php skim ext:install` CLI command. It runs the full installation pipeline: preflight DB check, composer require, extension discovery, config publishing, atomic migration execution (with rollback on failure), and post-install hints.

```txt
Symbol: Skim\Cli\Commands\ExtInstallCommand
Source: src/Cli/Commands/ExtInstallCommand.php
Lifecycle: instantiated by kernel, handle() called once per invocation
Fallback: migration failure triggers automatic rollback of all migrations applied in this session
Test seam: constructor accepts ExtRegistry and ExtMigrator test doubles
```

<CodeExample label="Basic usage" source="llm-generated">
```php
php skim ext:install skim/auth
php skim ext:install auth --prefix=myapp_ --no-interaction
```
</CodeExample>

<WarningBox>

Migration failure rolls back all migrations applied in this session

</WarningBox>

<WarningBox>

composer require modifies vendor/ and composer.json

</WarningBox>

## Architecture

<LifecycleFlow>

```txt
handle()
-> resolvePackage(arg(0))
-> preflight() checks PHP+DB
-> composerRequire(package)
-> registry->refresh()
-> registry->find(package)
-> publishConfig(extension)
-> tablePrefix()
-> writeTablePrefix()
-> migrator->run()
-> on failure: rollbackSession()
-> printEnvAdditions()
-> printPostInstall()
```

</LifecycleFlow>

Constructor injection of ExtRegistry and ExtMigrator enables full test isolation without filesystem or database side-effects.
