`InteractiveMenu` provides a full-screen, keyboard-driven terminal UI for browsing and selecting CLI commands. It supports collapsible command groups, live search with / or :, and ANSI-styled rendering. Returns null when not on a TTY.

```txt
Symbol: Skim\Cli\InteractiveMenu
Source: src/Cli/InteractiveMenu.php
Lifecycle: instantiated by kernel with command groups, run() enters event loop, returns selected command or null
Fallback: returns null immediately when not connected to a TTY
Test seam: not designed for automated testing — requires interactive TTY with raw mode
```

<CodeExample label="Basic usage" source="llm-generated">
```php
$menu = new InteractiveMenu($groups);
$selected = $menu->run(); // returns command name or null
```
</CodeExample>

## Architecture

<LifecycleFlow>

```txt
run()
-> isTty() check
-> setupTty() raw mode
-> register SIGINT handler
-> render() initial frame
-> loop: readKey() -> decodeKey() -> handleKey() -> render()
-> on quit: clearMenu() -> restoreTty()
-> return command name or null
```

</LifecycleFlow>

The menu takes full control of the terminal in raw mode. TTY settings are saved and restored in a finally block to prevent terminal corruption even on exceptions.

## TTY Management

<ApiMethod name="setupTty">

<ApiSignature>

```php

```

</ApiSignature>

Saves current TTY settings and puts terminal into raw mode for character-by-character input. Hides cursor.

</ApiMethod>

<ApiMethod name="restoreTty">

<ApiSignature>


</ApiSignature>

Restores original TTY settings and shows the cursor. Falls back to stty echo icanon if saved settings are unavailable.
