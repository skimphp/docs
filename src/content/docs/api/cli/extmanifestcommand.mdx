`ExtManifestCommand` implements the `php skim ext:manifest` CLI command. It takes a fully-qualified extension class name, validates it extends `extension`, and generates `skim.json` at the project root via `ExtManifest::generate()`.

```txt
Symbol: Skim\Cli\Commands\ExtManifestCommand
Source: src/Cli/Commands/ExtManifestCommand.php
Lifecycle: instantiated by kernel, handle() called once per invocation
Fallback: prints usage error when argument is missing or not a valid extension class
Test seam: instantiate directly, call setInput() with test args, then handle()
```

<CodeExample label="Basic usage" source="llm-generated">
```php

```
