`kernel` is the central dispatcher for the SKIM CLI. It owns the built-in command registry, merges user-defined commands from config, resolves command names, prints the header banner, dispatches commands with timing and error handling, and provides interactive or static help listings.

```txt
Symbol: Skim\Cli\Kernel
Source: src/Cli/Kernel.php
Lifecycle: instantiated once per CLI invocation in bin/skim, run() called with parsed argv
Fallback: unknown commands show error box with Levenshtein suggestion
Test seam: instantiate directly, pass ArgvParser with known input
```

<CodeExample label="Basic usage" source="llm-generated">
```php
$kernel = new Kernel();
$exit_code = $kernel->run(ArgvParser::parse($argv));
exit($exit_code);
```
</CodeExample>

## Architecture

<LifecycleFlow>

```txt
run(ArgvParser)
-> check --version/--quiet/--no-ansi
-> resolve(commandName)
-> if found: dispatch()
-> if help/list: showHelp()
-> if unknown: errorBox + didYouMean
-> return exit code
```

</LifecycleFlow>

The kernel is the single entry point for all CLI operations. It keeps the command registry as a private constant and merges user commands from config at runtime.
