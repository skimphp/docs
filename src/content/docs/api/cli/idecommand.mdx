`IdeCommand` implements the `php skim ide:generate` CLI command. It discovers model classes in app/Models, reads their database schema (from cache or DESCRIBE queries), and generates typed property stubs in `.skim/ide-helper.php` for IDE autocomplete.

```txt
Symbol: Skim\Cli\Commands\IdeCommand
Source: src/Cli/Commands/IdeCommand.php
Lifecycle: instantiated by kernel, handle() called once per invocation
Fallback: models that fail reflection or schema reads are silently skipped
Test seam: instantiate directly, call setInput() with test args, then handle()
```

<CodeExample label="Basic usage" source="llm-generated">
```php
php skim ide:generate
```
</CodeExample>

## Architecture

<LifecycleFlow>

```txt
handle()
-> discoverModels() globs app/Models
-> for each model: getColumns() via Model::schema()
-> stub() generates typed properties
-> buildOutput() assembles PHP source
-> file_put_contents(.skim/ide-helper.php)
```

</LifecycleFlow>

Output file is committed to git so IDEs can use it without running the app. The generated file uses @generated annotation to signal it should not be edited.
