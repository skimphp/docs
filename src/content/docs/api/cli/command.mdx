`command` is the abstract base class that all SKIM CLI commands extend. It provides positional arg access, flag access, output helper proxies (info, success, warn, error), and auto-configuration of name/group/description/usage from the registered command name.

```txt
Symbol: Skim\Cli\Command
Source: src/Cli/Command.php
Lifecycle: instantiated by kernel, setInput() called with parsed argv, then handle() invoked
Fallback: configureForName() provides default descriptions and usage strings for built-in commands
Test seam: instantiate subclass, call setInput() with test data, then handle()
```

<CodeExample label="Basic usage" source="llm-generated">
```php
class GreetCommand extends Command {
    public function handle(): int {
        $name = $this->arg(0, 'World');
        $this->info("Hello {$name}!");
        return 0;
    }
}
```
</CodeExample>

## Architecture

<LifecycleFlow>

```txt
kernel resolves command class
-> new $class()
-> configureForName($name)
-> setInput($args, $flags)
-> handle()
-> return exit code
```

</LifecycleFlow>

Abstract base class — never instantiated directly. Subclasses implement handle() and optionally override $name, $description, $group, $usage properties.
