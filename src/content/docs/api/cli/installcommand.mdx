`InstallCommand` implements the `php skim install` CLI command. It provides an interactive wizard that prompts for application, database, cache, and logging configuration, writes the results to `.env`, reloads env/config, and optionally runs migrations.

```txt
Symbol: Skim\Cli\Commands\InstallCommand
Source: src/Cli/Commands/InstallCommand.php
Lifecycle: instantiated by kernel, handle() called once per invocation
Fallback: existing .env is preserved unless --force or user confirms overwrite
Test seam: not designed for automated testing due to interactive STDIN prompts
```

<CodeExample label="Basic usage" source="llm-generated">
```php
php skim install              # interactive wizard
php skim install --force      # overwrite existing .env without prompting
php skim install --no-migrate # skip migration step
```
</CodeExample>

<WarningBox>

Overwrites .env when --force is passed or user confirms

</WarningBox>

<WarningBox>

DB password is shown in plain text during prompt

</WarningBox>

## Architecture

<LifecycleFlow>

```txt
handle()
-> check existing .env
-> prompt application config
-> prompt database config
-> prompt cache config
-> prompt logging config
-> buildEnv()
-> file_put_contents(.env)
-> Env::reset() + Env::load()
-> Config::reset() + Config::load()
-> optionally MigrateCommand::handle()
```

</LifecycleFlow>

After writing .env, the command reloads env and config so that subsequent migration runs use the newly written configuration values.
