`queue` is the static facade for the Redis-backed job queue. Jobs are serialized and LPUSHed into Redis lists. Workers dequeue with BRPOP for blocking, latency-free operation. Delayed jobs use a sorted set keyed by executeAt timestamp and are promoted to the main list by the worker.

```txt
Symbol: Skim\Queue\Queue
Source: src/Queue/Queue.php
Lifecycle: static facade, Redis connection resolved lazily on first use from config
Fallback: none — Redis connection failure throws
Test seam: setRedis() to inject mock Redis, flush() to clear queues
```

<CodeExample label="Basic usage" source="llm-generated">
```php
Queue::push(new SendEmailJob($user_id));
Queue::push(new GenerateReportJob($id), queue: 'reports');
Queue::pushMany([$job1, $job2], 'default');
```
</CodeExample>

## Architecture

<LifecycleFlow>

```txt
Queue::push(job)
-> serializeJob(job, queue)
-> job->delay() > 0 ? ZADD delayedKey : LPUSH skim:queue:$queue
-> worker BRPOP
-> deserialize()
-> unserialize payload
-> handle()
```

</LifecycleFlow>

Static facade sharing the Redis connection with the cache subsystem via config. The connection is lazy — not opened until the first queue operation.

## Enqueue

Pushes a job to the queue. Jobs with delay &gt; 0 go into a sorted set

<ApiSignature>


</ApiSignature>

Pushes multiple jobs atomically via Redis pipeline. All jobs use the same queue. Does not support delayed jobs.

<ApiParam name="$jobs" type="array" required>

Array of job instances.

</ApiParam>

<ApiParam name="$queue" type="string">

Queue name for all jobs.

</ApiMethod>

## Delayed Jobs

<ApiMethod name="promoteDelayed">

<ApiSignature>

```php
public static function promoteDelayed(): int
```

</ApiSignature>

Moves due delayed jobs from the sorted set to their target queue. Called by worker on each loop iteration.

</ApiMethod>

## Queue Inspection

<ApiMethod name="size">

<ApiSignature>

```php
public static function size(string $queue = 'default'): int
```

</ApiSignature>

Returns the approximate count of pending jobs in a queue via Redis LLEN.

<ApiParam name="$queue" type="string">

Queue name.

</ApiParam>

</ApiMethod>

<ApiMethod name="flush">

<ApiSignature>

```php
public static function flush(string $queue = 'default'): void
```

</ApiSignature>

Removes all pending jobs from a queue by deleting the Redis key.

<ApiParam name="$queue" type="string">

Queue name to flush.

</ApiParam>

<WarningBox>

Destroys all pending jobs in the queue — already-processing jobs are not affected

</WarningBox>

</ApiMethod>
