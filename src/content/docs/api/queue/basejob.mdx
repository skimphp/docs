`BaseJob` is a convenience abstract class that implements the `job` interface with sensible defaults: 3 retry attempts, 0-second delay, and error_log on permanent failure. Most job classes extend this and override only `handle()`.

```txt
Symbol: Skim\Queue\BaseJob
Source: src/Queue/BaseJob.php
Lifecycle: instantiated by worker via unserialize, handle() called, failed() called on exhaustion
Fallback: failed() logs to error_log by default — override for custom failure handling
Test seam: extend in test job classes, override failed() to capture errors
```

<CodeExample label="Basic usage" source="llm-generated">
```php
class SendEmailJob extends BaseJob {
    public function __construct(private readonly int $user_id) {}
    public function handle(): void {
        $user = User::findOrFail($this->user_id);
        Mailer::send($user->email, 'welcome');
    }
}
```
</CodeExample>

## Architecture

<LifecycleFlow>

```txt
worker unserializes BaseJob subclass
-> handle() called
-> on exception: worker retries up to tries() times
-> on exhaustion: failed($e) called
```

</LifecycleFlow>

Abstract class implementing the job interface. Subclasses must implement handle() and may override tries(), delay(), and failed().

## Failure Handling

<ApiMethod name="failed">

<ApiSignature>

```php
public function failed(\Throwable $e): void
```

</ApiSignature>

Logs the error when all retries are exhausted. Default writes to error_log. Override for alerts or dead-letter handling.

<ApiParam name="$e" type="\Throwable" required>

The exception that caused the final failure.

</ApiParam>

<NoteBox>

Does not rethrow — the worker catches any exception from failed() anyway.

</NoteBox>

</ApiMethod>
