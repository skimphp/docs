## Emit

<ApiMethod name="emit">

<ApiSignature>

```php
public function emit(array $data, string $outputDir): int
```

</ApiSignature>

Accepts decoded llm.json array and writes one MDX file per class into namespace subdirectories under the output directory. Also writes an index.mdx landing page. Returns the count of files written. Handles duplicate class names and filename collisions. Cleans stale .mdx files before writing.

<ApiParam name="$data" type="array" required>

Decoded llm.json array with 'classes' key.

</ApiParam>

<ApiParam name="$outputDir" type="string" required>

Directory to write .mdx files into. Created if it does not exist.

</ApiParam>

<ApiThrows type="\RuntimeException">

When a file cannot be written.

</ApiThrows>

</ApiMethod>
