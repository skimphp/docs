`McpServeCommand` spawns the `skim-mcp` native binary as a child process communicating over stdio. It validates that llm.json and the binary exist before launching, and forwards the child's exit code.

```txt
Symbol: Skim\Dev\Docs\Commands\McpServeCommand
Source: src/Dev/Docs/Commands/McpServeCommand.php
Lifecycle: instantiated by CLI router, runs until stdin closes or Ctrl+C
Fallback: none — returns 1 when prerequisites are missing
Test seam: instantiate directly
```

<CodeExample label="Basic usage" source="llm-generated">
