`DocsGenerationPaths` encapsulates the resolution logic for docs generation file paths. It merges CLI flag overrides with config/docs.php defaults, handling relative-to-absolute path resolution.

```txt
Symbol: Skim\Dev\Docs\Value\DocsGenerationPaths
Source: src/Dev/Docs/Value/DocsGenerationPaths.php
Lifecycle: instantiated per-command via fromFlags(), immutable after construction
Fallback: falls back to config/docs.php values when flags are absent
Test seam: instantiate directly with constructor args
```

<CodeExample label="Basic usage" source="llm-generated">
```php
$paths = DocsGenerationPaths::fromFlags($this->flags);
$json  = $paths->jsonPath();
$scan  = $paths->scanPaths();
```
</CodeExample>

## Path Resolution

<ApiMethod name="scanPaths">

<ApiSignature>

```php

```

Returns the explicit source override as a single-element array, or falls back to config('docs.scan_paths'). Relative paths resolve from basePath().

</ApiMethod>

<ApiMethod name="hasSourceOverride">

<ApiSignature>

</ApiMethod>
