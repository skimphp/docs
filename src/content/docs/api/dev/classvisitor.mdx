`ClassVisitor` is the AST traversal engine used by `ClassExtractor`. It visits namespace and class nodes, merges annotations from three sources (PHPDoc, inline //, detached #AI blocks), and builds `ExtractedClass` and `ExtractedMethod` value objects.

```txt
Symbol: Skim\Dev\Docs\Extractor\ClassVisitor
Source: src/Dev/Docs/Extractor/ClassVisitor.php
Lifecycle: created per-file by ClassExtractor, single-use
Fallback: none — captures first non-anonymous class only
Test seam: use via ClassExtractor
```

## Architecture

<LifecycleFlow>

```txt
enterNode()
-> namespace tracking
-> Class_ detection
-> PHPDoc or inline parse
-> detached block merge
-> method iteration
-> extractMethod()
-> build ExtractedClass
```

</LifecycleFlow>

Not part of the public API — only instantiated by ClassExtractor.

## Traversal

<ApiMethod name="enterNode">

<ApiSignature>

```php
public function enterNode(Node $node): null
```

</ApiSignature>

Visits each AST node. Tracks namespace context and captures the first non-anonymous class with all its annotated methods. Merges tags from PHPDoc, inline comments, trailing comment #AI blocks, and detached #AI blocks.

</ApiMethod>

## Extraction

<ApiMethod name="extractMethod">

<ApiSignature>

```php
private function extractMethod(ClassMethod $method, string $owner, array $tags): ExtractedMethod
```

</ApiSignature>

Builds an ExtractedMethod from a ClassMethod AST node and its merged annotation tags. Constructs the method signature string from AST type nodes.

</ApiMethod>

<ApiMethod name="parseDetachedBlocks">

<ApiSignature>

```php
private function parseDetachedBlocks(): array
```

</ApiSignature>

Reads the source file and parses all detached #AI blocks at the bottom into class-level and method-level tag arrays. Uses #AI:&#123;target&#125; headers to determine section boundaries.

</ApiMethod>
