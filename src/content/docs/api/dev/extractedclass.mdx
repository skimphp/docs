`ExtractedClass` is the immutable data carrier between the AST extraction pipeline and all downstream emitters. It holds every annotation field extracted from a single PHP class file.

```txt
Symbol: Skim\Dev\Docs\Value\ExtractedClass
Source: src/Dev/Docs/Value/ExtractedClass.php
Lifecycle: created once by ClassExtractor, never mutated, serialized by emitters
Fallback: toArray() falls back to namespace\className for symbol, className for title
Test seam: instantiate directly with test data
```

<CodeExample label="Basic usage" source="llm-generated">
```php
$class = $extractor->extract('/path/to/file.php');
$array = $class->toArray();  // for json_encode
```
</CodeExample>
