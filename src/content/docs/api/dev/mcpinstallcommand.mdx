`McpInstallCommand` detects the host OS/architecture, downloads the matching `skim-mcp` release asset from the skim_mcp repository, and installs it to `.skim/bin/skim-mcp` with executable permissions.

```txt
Symbol: Skim\Dev\Docs\Commands\McpInstallCommand
Source: src/Dev/Docs/Commands/McpInstallCommand.php
Lifecycle: instantiated by CLI router per invocation
Fallback: returns 1 on unsupported platform, network failure, or empty download
Test seam: instantiate directly, call setInput(), then handle()
```

<CodeExample label="Basic usage" source="llm-generated">
```php

php skim mcp:install --force
```
