`DocsValidateCommand` scans all source files, counts public methods with at least one @ai.* annotation, and compares the ratio against a configurable threshold. Use in CI pipelines or pre-commit hooks to prevent annotation regressions.

```txt
Symbol: Skim\Dev\Docs\Commands\DocsValidateCommand
Source: src/Dev/Docs/Commands/DocsValidateCommand.php
Lifecycle: instantiated by CLI router, runs synchronously
Fallback: none — returns 1 on scan failure or below-threshold coverage
Test seam: instantiate directly
```

<CodeExample label="Basic usage" source="llm-generated">

# In .git/hooks/pre-push: php skim docs:validate || exit 1

Designed for CI gate usage — non-zero exit code blocks merges when coverage drops.
