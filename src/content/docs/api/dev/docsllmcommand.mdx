`DocsLlmCommand` converts the structured llm.json into a single grouped Markdown file (llm.md) that fits within LLM context windows. Optionally prepends the framework-level llm.md for full API context.

```txt
Symbol: Skim\Dev\Docs\Commands\DocsLlmCommand
Source: src/Dev/Docs/Commands/DocsLlmCommand.php
Lifecycle: instantiated by CLI router or DocsCommand, runs synchronously
Fallback: none — returns 1 when llm.json is missing or write fails
Test seam: instantiate directly with setInput() to inject flags
```

<CodeExample label="Basic usage" source="llm-generated">
```php
php skim docs:llm
php skim docs:llm --output=build/docs
```
</CodeExample>

## Architecture

<LifecycleFlow>

```txt
handle()
-> resolve paths
-> JsonEmitter.load(llm.json)
-> optionally load framework llm.md
-> LlmMdEmitter.emit()
-> llm.md written
```

</LifecycleFlow>

Requires docs:extract to have been run first
