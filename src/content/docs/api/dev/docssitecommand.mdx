`DocsSiteCommand` converts the structured llm.json into component-style MDX files suitable for a Starlight/Astro documentation site. Each class becomes one .mdx file

```txt
Symbol: Skim\Dev\Docs\Commands\DocsSiteCommand
Source: src/Dev/Docs/Commands/DocsSiteCommand.php
Lifecycle: instantiated by CLI router or DocsCommand, runs synchronously
Fallback: none — returns 1 when llm.json is missing or write fails
Test seam: instantiate directly with setInput() to inject flags
```

<CodeExample label="Basic usage" source="llm-generated">
```php
php skim docs:site
php skim docs:site --output=build/docs
```
</CodeExample>

## Architecture

<LifecycleFlow>

```txt
handle()
-> resolve paths
-> JsonEmitter.load(llm.json)
-> MdxEmitter.emit()
-> MDX files written
```

</LifecycleFlow>

Requires docs:extract to have been run first
