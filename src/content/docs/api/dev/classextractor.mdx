`ClassExtractor` parses a single PHP file using nikic/php-parser, delegates AST traversal to `ClassVisitor`, and returns an `ExtractedClass` value object. It silently returns null for non-class files, unreadable files, and parse errors.

```txt
Symbol: Skim\Dev\Docs\Extractor\ClassExtractor
Source: src/Dev/Docs/Extractor/ClassExtractor.php
Lifecycle: instantiated per-use by ProjectScanner, parser created once in constructor
Fallback: returns null on any failure (missing file, parse error, no class)
Test seam: instantiate directly with test file paths
```

## Architecture

<LifecycleFlow>

```txt
extract()
-> is_file/is_readable check
-> file_get_contents
-> parser->parse()
-> ClassVisitor traversal
-> return visitor->result
```

</LifecycleFlow>

Uses nikic/php-parser for reliable AST traversal — never regex on source code.
