`DocsExtractCommand` is the first step in the docs pipeline. It uses `ProjectScanner` to walk source paths, runs `ClassExtractor` on each .php file, enriches the result with extension capability data from `ExtRegistry`, and writes the output to llm.json via `JsonEmitter`.

```txt
Symbol: Skim\Dev\Docs\Commands\DocsExtractCommand
Source: src/Dev/Docs/Commands/DocsExtractCommand.php
Lifecycle: instantiated by CLI router or DocsCommand, runs synchronously
Fallback: none — returns 1 on scan or write failure
Test seam: instantiate directly with setInput() to inject flags
```

<CodeExample label="Basic usage" source="llm-generated">
```php
php skim docs:extract
php skim docs:extract --source=app --output=build/docs
```
</CodeExample>

## Architecture

<LifecycleFlow>

```txt
handle()
-> resolve paths from flags/config
-> ProjectScanner.scan()
-> ExtRegistry.installed()
-> JsonEmitter.emit()
-> llm.json written
```

</LifecycleFlow>

Separates scanning, enrichment, and writing into distinct steps for clear error reporting.
