`DevView` is a minimal, self-contained template renderer for dev tool HTML output. It supports layouts, named slots, and partial includes with the same API patterns as `Skim\View\Template`, but has zero dependencies on any framework module — ensuring it works even when the view system, config, or profiler is broken.

```txt
Symbol: Skim\Dev\DevView
Source: src/Dev/DevView.php
Lifecycle: instantiated per render() call, stateless between calls
Fallback: throws RuntimeException when template file is missing
Test seam: call render() with data arrays, assert HTML output
```

<CodeExample label="Basic usage" source="llm-generated">
```php
echo DevView::render('error_page', [
    'exception' => $e,
    'context'   => $code_lines,
]);
```

## Architecture

<LifecycleFlow>

```txt
render($template, $data)
→ new DevView(path, data)
→ renderFile($template)
→ resolve .php
→ extract data
→ ob_start + include
→ layout declared? → capture content slot
→ render layout file
→ return HTML
```

</LifecycleFlow>

Deliberately duplicates ~60 lines from Skim\View\Template to eliminate any dependency on the framework's view system. This ensures the error page renders even when the view system itself throws.

## Rendering

<ApiMethod name="render">

<ApiSignature>

```php
public static function render(string $template, array $data = []): string
```

</ApiSignature>

Renders a template file with data extracted as locals. When the template declares a layout, wraps output in the layout with slot access. Returns the final HTML string.

<ApiParam name="$template" type="string" required>

Template path relative to src/dev/views/, no .php extension needed.

</ApiParam>

<ApiParam name="$data" type="array">

Key-value pairs extracted as local variables inside the template.

</ApiParam>

<ApiThrows type="\RuntimeException">

If the template .php file does not exist in src/dev/views/.

</ApiThrows>

</ApiMethod>

<ApiMethod name="renderFile">

<ApiSignature>

```php
public function renderFile(string $template): string
```

</ApiSignature>

Renders a single template file by resolving the .php extension, extracting data as local variables, and including the file within an output buffer.

<ApiParam name="$template" type="string" required>

Template path relative to views root, no extension.

</ApiParam>

<ApiThrows type="\RuntimeException">

If the template file does not exist.

</ApiThrows>

</ApiMethod>

## Layout System

<ApiMethod name="layout">

<ApiSignature>

```php
public function layout(string $name): void
```

</ApiSignature>

Declares the layout template to wrap this template's output. Must be called before any output.

<ApiParam name="$name" type="string" required>

Layout template path relative to src/dev/views/, no extension.

</ApiParam>

</ApiMethod>

<ApiMethod name="start">

<ApiSignature>

```php
public function start(string $name): void
```

</ApiSignature>

Starts capturing output into a named slot. Must be paired with end().

<ApiParam name="$name" type="string" required>

Slot identifier used by the layout to retrieve content.

</ApiParam>

</ApiMethod>

<ApiMethod name="end">

<ApiSignature>

```php
public function end(): void
```

</ApiSignature>

Ends the slot capture started by start(). Stores captured output in the named slot.

<ApiThrows type="\LogicException">

If called without a matching start().

</ApiThrows>

</ApiMethod>

<ApiMethod name="slot">

<ApiSignature>

```php
public function slot(string $name): string
```

</ApiSignature>

Returns captured slot content for use inside layout files. Returns empty string if the slot was never captured.

<ApiParam name="$name" type="string" required>

Slot identifier matching a previous start()/end() pair.

</ApiParam>

</ApiMethod>
