`toolbar` generates a fixed-bottom debug panel with tabbed views for request info, DB queries, cache statistics, timeline breakdown, rendered views, and log entries. It reads all data from Profiler::summary() and Profiler::events().

```txt
Symbol: Skim\Dev\Toolbar
Source: src/Dev/Toolbar.php
Lifecycle: called by ToolbarMiddleware after controller returns, before response is sent
Fallback: returns empty string when APP_DEBUG=false
Test seam: call render() with a mock request after populating profiler
```
