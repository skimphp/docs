`LlmMdEmitter` transforms the structured llm.json array into a single Markdown file with class sections grouped by section_order. It renders compact signatures, param tables, and warning annotations in a format that fits within LLM context windows.

```txt
Symbol: Skim\Dev\Docs\Emitter\LlmMdEmitter
Source: src/Dev/Docs/Emitter/LlmMdEmitter.php
Lifecycle: instantiated per-use by DocsLlmCommand, no state retained
Fallback: none — throws on write failure
Test seam: instantiate directly with temp file paths
```

<CodeExample label="Basic usage" source="llm-generated">
```php
$data = (new JsonEmitter())->load('llm.json');
(new LlmMdEmitter())->emit($data, 'llm.md', frameworkLlmMd: 'vendor/skim/framework/llm.md');
```
</CodeExample>

## Architecture

<LifecycleFlow>

```txt
emit()
-> build header lines
-> optionally prepend framework llm.md
-> iterate classes
-> renderClass()
-> groupMethods()
-> renderMethod()
-> write()
```

</LifecycleFlow>

Produces a single-file Markdown output designed for paste-into-LLM usage, not for human browsing.

## Emit

<ApiMethod name="emit">

<ApiSignature>

```php
public function emit(array $data, string $outputPath, ?string $frameworkLlmMd = null): void
```

</ApiSignature>

Accepts decoded llm.json array and writes compact class sections grouped by section_order. Prepends framework llm.md content when the optional path is provided and the file exists.

<ApiParam name="$data" type="array" required>

Decoded llm.json array with 'classes' and 'generated_at' keys.

</ApiParam>

<ApiParam name="$outputPath" type="string" required>

Filesystem path for the output Markdown file.

</ApiParam>

<ApiParam name="$frameworkLlmMd" type="?string">

Optional path to framework-level llm.md to prepend.

</ApiParam>

<ApiThrows type="\RuntimeException">

When the output directory cannot be created or the file cannot be written.

</ApiThrows>

</ApiMethod>
