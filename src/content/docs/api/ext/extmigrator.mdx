`ExtMigrator` applies an extension's migration files inside transactions and tracks them in the shared `_migrations` table. It supports session-scoped rollback for cleanup when installation fails partway through.

```txt
Symbol: Skim\Ext\ExtMigrator
Source: src/Ext/ExtMigrator.php
Lifecycle: instantiated per-extension install
Test seam: use SQLite :memory: connection
```

<CodeExample label="Basic usage" source="llm-generated">
```php
$migrator = new ExtMigrator('default');
$applied = $migrator->run('acme/auth', __DIR__ . '/migrations');
// On failure:
$migrator->rollbackSession($applied);
```
</CodeExample>

<WarningBox>

rollbackSession() only rolls back migrations from the current run() call — not previous sessions

</WarningBox>

<ApiMethod name="run">

<ApiSignature>

```php
public function run(string $extName, string $migrationsPath): array
```

</ApiSignature>

Scans the migrations path, compares against applied migrations, and applies pending ones inside transactions. Returns the list of applied entries.

<ApiParam name="$extName" type="string" required>

Extension name. Must be non-empty and cannot contain colons.

</ApiParam>

<ApiParam name="$migrationsPath" type="string" required>

Absolute path to directory containing migration .php files.

</ApiParam>

<CodeExample label="Basic usage" source="llm-generated">
```php
$applied = $migrator->run('acme/auth', '/path/to/ext/migrations');
```
</CodeExample>

</ApiMethod>

<ApiMethod name="rollbackSession">

<ApiSignature>

```php
public function rollbackSession(array $appliedThisSession): array
```

</ApiSignature>

Rolls back migrations applied during the current install session in reverse order. Each rollback runs inside a transaction.

<ApiParam name="$appliedThisSession" type="array" required>

Array of applied entries returned by run().

</ApiParam>

<WarningBox>

Only rolls back migrations from the most recent run() call — not previous sessions

</WarningBox>

</ApiMethod>
