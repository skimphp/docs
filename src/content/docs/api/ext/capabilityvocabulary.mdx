`CapabilityVocabulary` defines the canonical set of capability slugs that SKIM extensions can declare. It provides a lookup method and a constant map for display or validation purposes.

```txt
Symbol: Skim\Ext\CapabilityVocabulary
Source: src/Ext/CapabilityVocabulary.php
Lifecycle: stateless, all data in class constant
Test seam: none needed — pure constant lookup
```

<CodeExample label="Basic usage" source="llm-generated">
```php
CapabilityVocabulary::isKnown('auth');        // true
CapabilityVocabulary::TERMS['rate-limiting'];  // 'request rate limiting'
```
</CodeExample>
