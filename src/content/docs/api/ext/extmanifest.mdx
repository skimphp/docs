`ExtManifest` serializes an extension instance's metadata into a pretty-printed JSON file. The generated skim.json allows ExtRegistry to read extension data without class instantiation.

```txt
Symbol: Skim\Ext\ExtManifest
Source: src/Ext/ExtManifest.php
Lifecycle: stateless, one-shot file write
Test seam: pass a mock extension and temp path
```

<CodeExample label="Basic usage" source="llm-generated">

