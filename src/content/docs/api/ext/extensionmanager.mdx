## Lifecycle Hooks

<ApiMethod name="register">

<ApiSignature>

```php
public function register(App $app): void
```

</ApiSignature>

Calls register(app) for every extension in dependency-sorted order. Throws immediately if conflicts exist.

<ApiParam name="$app" type="app" required>

Application container.

</ApiParam>

<ApiThrows type="\RuntimeException">

When extension conflicts are detected.

</ApiThrows>

</ApiMethod>

<ApiMethod name="boot">

<ApiSignature>

```php
public function boot(App $app): void
```

</ApiSignature>

Calls boot(app) for every extension in dependency-sorted order. Runs after all extensions have been registered.

<ApiParam name="$app" type="app" required>

Application container.

</ApiParam>

</ApiMethod>
