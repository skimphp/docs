`ExtRegistry` scans vendor/ Composer packages for SKIM extension metadata. It reads extra.skim from composer.json and optional skim.json manifests, builds a capability map, detects conflicts, and caches results for the instance lifetime.

```txt
Symbol: Skim\Ext\ExtRegistry
Source: src/Ext/ExtRegistry.php
Lifecycle: instantiated per-discovery
Test seam: construct with temp directory containing mock vendor/ structure
```

<CodeExample label="Basic usage" source="llm-generated">
```php
$registry = new ExtRegistry(basePath());
$extensions = $registry->installed();
$auth = $registry->find('acme/auth');
```
</CodeExample>
