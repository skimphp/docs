`db` is the static entry point for all raw SQL operations. It uses query_gen `%placeholder%` templates processed by `QueryBuilder` (internal). Connections are lazy — PDO is created on first query, not on config load. All queries are recorded in the profiler when APP_DEBUG is enabled.

```txt
Symbol: Skim\Db\Db
Source: src/Db/Db.php
Lifecycle: static facade, connections resolved lazily on first query per named connection
Fallback: none — missing connection config throws RuntimeException
Test seam: test_db() for SQLite :memory:, reset() to clear connection pool
```

<CodeExample label="Basic usage" source="llm-generated">
```php
$users = Db::all('SELECT * FROM users %where% %limit%', [
    'where' => ['status = :status'], ':status' => 'active', 'limit' => 20,
]);
Db::transaction(fn() => Db::query('UPDATE accounts %set% WHERE id = :id', [
    'set' => ['balance' => 100], ':id' => 1,
]));
```
</CodeExample>

<WarningBox>

Always use transaction() for multi-table writes

</WarningBox>

<WarningBox>

Always use limit on large tables with all()

</WarningBox>

## Architecture

<LifecycleFlow>

```txt
Db::query/val/row/all()
-> QueryBuilder::build(sql, params)
-> pdo(connection) auto-connects if needed
-> PDO prepare + execute
-> Profiler::db() records timing
-> return rows/scalar/count
```

</LifecycleFlow>

The facade keeps raw SQL as the primary interface. QueryBuilder handles %placeholder% substitution internally — it is not part of the public API.

<NoteBox>

The connection pool is process-local. Call reset() in test tearDown() to clear connections.

</NoteBox>

</ApiMethod>

## Transactions

<ApiMethod name="transaction">

<ApiSignature>

```php
public static function transaction(callable $fn, string $connection = 'default'): mixed
```

</ApiSignature>

Wraps $fn in BEGIN/COMMIT. Auto-ROLLBACK on any Throwable. The original exception is rethrown after rollback — never swallowed.

<ApiParam name="$fn" type="callable" required>

Code to execute inside the transaction.

</ApiParam>

<ApiParam name="$connection" type="string">

Named DB connection.

</ApiParam>

<CodeExample label="Basic usage" source="llm-generated">
```php
Db::transaction(function() {
    Db::query('UPDATE accounts %set% WHERE id = :id', ['set' => ['balance' => 100], ':id' => 1]);
    Db::query('UPDATE accounts %set% WHERE id = :id', ['set' => ['balance' => 200], ':id' => 2]);
});
```
</CodeExample>

<WarningBox>

Always use for multi-table writes — partial writes corrupt data

</WarningBox>

</ApiMethod>

## Utilities

<ApiMethod name="null">

<ApiSignature>

```php
public static function null(): NullMarker
```

</ApiSignature>

Returns a NullMarker sentinel for use in %set% to force SET col = NULL. Plain null skips the column.

<CodeExample label="Basic usage" source="llm-generated">
```php
Db::query('UPDATE users %set% WHERE id = :id', [
    'set' => ['avatar' => Db::null()], ':id' => 5,
]);
```
</CodeExample>

</ApiMethod>
