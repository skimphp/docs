`model` is the active record base class for all database-backed models. It provides find/create/save/delete operations with automatic dirty tracking for efficient UPDATE queries, schema caching for introspection, guarded mass-assignment protection, and configurable type casting.

```txt
Symbol: Skim\Db\Model
Source: src/Db/Model.php
Lifecycle: instantiated via find/create/new, persisted via save(), schema cached per table for 1 hour
Fallback: none
Test seam: test_db() for SQLite :memory:, models work directly against it
```

<CodeExample label="Basic usage" source="llm-generated">
```php
class User extends Model {
    protected static string $table = 'users';
    public string $email { set(string $val) => strtolower(trim($val)); }
}
$user = User::find(1);           // model|null
$user = User::findOrFail(1);   // model|throws
User::create(['name' => 'John', 'email' => 'J@J.COM']);
```
</CodeExample>

<WarningBox>

all() defaults to limit 1000 — always paginate large tables

</WarningBox>

<WarningBox>

deleteWhere() has no limit — deletes ALL matching rows

</WarningBox>

## Architecture

<LifecycleFlow>

```txt
Model::find/create/new
-> hydration or fill()
-> attribute assignment with dirty tracking
-> save() checks PK presence
-> doInsert() or doUpdate()
-> Db::query() with %values% or %set%
-> dirtyCols reset
```

</LifecycleFlow>

Active record pattern with dirty tracking for efficient updates. Schema caching avoids repeated DESCRIBE calls. Guarded columns protect against mass-assignment vulnerabilities.

<NoteBox>

Subclasses should use PHP 8.4 property hooks for normalization and asymmetric visibility for id/timestamps.

</NoteBox>

## Finders

<ApiMethod name="find">

<ApiSignature>

```php
public static function find(int|string $id): ?static
```

</ApiSignature>

Finds a record by primary key. Returns null if not found — never throws.

<ApiParam name="$id" type="int" required>

Primary key value.

</ApiParam>

</ApiMethod>

<ApiMethod name="findOrFail">

<ApiSignature>

```php
public static function findOrFail(int|string $id): static
```

</ApiSignature>

Finds a record by primary key. Throws NotFoundException if missing — use in controllers for 404 responses.

<ApiParam name="$id" type="int" required>

Primary key value.

</ApiParam>

<ApiThrows type="NotFoundException">

When no record matches the primary key.

</ApiThrows>

</ApiMethod>

<ApiMethod name="findBy">

<ApiSignature>

```php
public static function findBy(string $col, mixed $val): ?static
```

</ApiSignature>

Finds the first record matching a column=value condition. Validates column name against injection. Returns null if no match.

<ApiParam name="$col" type="string" required>

Column name (validated as identifier).

</ApiParam>

<ApiParam name="$val" type="mixed" required>

Value to match.

</ApiParam>

<ApiThrows type="\InvalidArgumentException">

If column name contains invalid characters.

</ApiThrows>

</ApiMethod>

<ApiMethod name="all">

<ApiSignature>

```php
public static function all(int $limit = 1000): array
```

</ApiSignature>

Returns all rows as hydrated models. Default limit of 1000 prevents accidental full-table scans.

<ApiParam name="$limit" type="int">

Maximum rows to return. Default 1000.

</ApiParam>

</ApiMethod>

## Query Building

<ApiMethod name="where">

<ApiSignature>

```php
public static function where(string|array $conditions, array $params = []): QueryScope
```

</ApiSignature>

Returns a QueryScope for building filtered queries. Chain order/limit/paginate before terminal methods.

<ApiParam name="$conditions" type="string" required>

SQL fragment or column=&gt;value pairs.

</ApiParam>

<ApiParam name="$params" type="array">

PDO params when conditions is a string.

</ApiParam>

<CodeExample label="Basic usage" source="llm-generated">
```php

```
</CodeExample>

<NoteBox>

#[\NoDiscard] — always capture or chain the return value.

</NoteBox>

</ApiMethod>
