`NullMarker` is a value object used exclusively in `%set%` placeholder arrays to force `SET col = NULL`. Plain PHP `null` skips the column entirely (partial-update pattern), while `Db::null()` produces a `NullMarker` that the query builder translates to literal `NULL`.

```txt
Symbol: Skim\Db\NullMarker
Source: src/Db/NullMarker.php
Lifecycle: stateless value object, created per use
Fallback: none
Test seam: none needed — pure value object
```

<CodeExample label="Basic usage" source="llm-generated">
```php
Db::query('UPDATE users %set% WHERE id = :id', [
    'set' => ['avatar' => Db::null(), 'name' => 'Jane'], ':id' => 5,
]);
```
</CodeExample>

## Architecture

<LifecycleFlow>

```txt
Db::null()
-> NullMarker::make()
-> passed in %set% array
-> QueryBuilder::buildSet() instanceof check
-> emits col = NULL
```

</LifecycleFlow>

The sentinel pattern avoids ambiguity between "skip this column" and "set to NULL" in partial updates.

<NoteBox>

Never instantiate directly. Always use `Db::null()` which delegates to `NullMarker::make()`.

</NoteBox>
