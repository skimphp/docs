`QueryBuilder` processes SQL templates with `%placeholder%` tokens into executable SQL and PDO parameter arrays. It is internal to the `db` facade — not part of the public SKIM API. Unused placeholders are stripped silently, enabling dynamic queries without conditionals.

```txt
Symbol: Skim\Db\QueryBuilder
Source: src/Db/QueryBuilder.php
Lifecycle: stateless — called per query by Db:: methods
Fallback: none
Test seam: use Db::query(..., debug: true) to inspect generated SQL
```

<WarningBox>

interpolate() output is NOT safe to execute — for debug display only

</WarningBox>

## Architecture

<LifecycleFlow>

```txt
Db::query/val/row/all()
-> QueryBuilder::build(sql, params)
-> process %set%/%values%/%where%/%order_by%/%group_by%/%limit%/%offset%
-> strip unused placeholders
-> collect :named params
-> return [sql, pdoParams]
```

</LifecycleFlow>

QueryBuilder is the engine behind query_gen. It processes templates in a fixed order to avoid key conflicts between %set% and %where% params.

<NoteBox>

This class is internal. Application code should use Db::query/val/row/all which delegate to QueryBuilder.

</NoteBox>

## Core Processing

<ApiMethod name="build">

<ApiSignature>

```php
public static function build(string $sql, array $params): array
```

</ApiSignature>

Processes a SQL template with %placeholders% into executable SQL and PDO params. Unused placeholders are stripped. Null :named params are excluded.

<ApiParam name="$sql" type="string" required>

SQL template with %placeholders%.

</ApiParam>

<ApiParam name="$params" type="array" required>

Placeholder values and :named params.

</ApiParam>

</ApiMethod>

<ApiMethod name="buildSet">

<ApiSignature>

</ApiSignature>

Builds a SET clause for UPDATE. Null skips the column, NullMarker forces SET col = NULL.

</ApiParam>

</ApiMethod>
