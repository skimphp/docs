`ToolbarMiddleware` appends the SKIM debug toolbar before `</body>` in HTML responses. It only activates when debug mode is enabled and the request is a standard page load (not JSON, AJAX, or hypermedia).

```txt
Symbol: Skim\Middleware\ToolbarMiddleware
Source: src/Middleware/ToolbarMiddleware.php
Lifecycle: registered as global middleware
Test seam: set app.debug to false to disable
```

<CodeExample label="Basic usage" source="llm-generated">
```php
// Registered globally in app boot — no manual setup needed
$app->use(ToolbarMiddleware::class);
```
</CodeExample>
