`RateLimit` uses a Redis sorted set sliding window to count requests per IP. When the limit is exceeded, it returns 429. When Redis is unavailable, it fails open and passes all requests through.

```txt
Symbol: Skim\Middleware\RateLimit
Source: src/Middleware/RateLimit.php
Lifecycle: registered per-route or per-group
Fallback: passthrough (no rate limiting) when Redis is unreachable
Test seam: mock Redis or test with Redis available
```

<CodeExample label="Basic usage" source="llm-generated">
```php
$app->router->group('/api', function(Router $r) {
    $r->get('/data', [api_controller::class, 'index']);
}, middleware: [new RateLimit(limit: 100, window: 60)]);
```
